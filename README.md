# 🧪 Molecular Virtual Laboratory

Type any molecule, compound or element (name, formula, element symbol or SMILES) and explore it.

- 🧬 Molecular Visualization: 2D and interactive 3D structures
- 📊 Molecular Properties Report: identifiers, 20+ properties, composition, atoms, bonds, functional groups
- 📈 Structure–Property Analysis: Lipinski rule, polarity, comparison charts
- 📄 PDF report with 2D and 3D structures, plus a quiz

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
